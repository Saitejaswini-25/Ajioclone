
# Ajio Clone - Landing Page

A visually engaging clone of the **Ajio landing page**, built using pure **HTML** and **CSS**. This project focuses on recreating the design and user interface of Ajio with smooth **CSS animations and transitions**.

## ✨ Features

- Responsive header with navigation menu
- Styled banner and promotional sections
- Animated hover effects on Discounts 
- CSS transitions and animations for smooth interactions
- Clean layout using Flexbox and Grid

>  **Note**: This is a static clone of the landing page. It’s not functional and is created only for learning and design purposes.

## 🔨 Tech Stack

- HTML5
- CSS3 (with animations & transitions)
